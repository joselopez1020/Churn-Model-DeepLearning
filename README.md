# Churn-Model-DeepLearning

Churn-Model-DeepLearning

Predicción de Churn de clientes de un banco mediante una red neuronal (TensorFlow/Keras)

En este portafolio construimos un modelo de deep learning para responder a la misma pregunta de negocio: ¿el cliente se va a ir o va a continuar en la institución? A diferencia de la versión con Random Forest, aquí abordamos el problema con una red neuronal

Para crear el modelo utilizamos:

Python · Pandas · NumPy · TensorFlow/Keras · scikit-learn · Matplotlib · Seaborn

El dataset utilizado fue obtenido desde Kaggle

Link: https://www.kaggle.com/datasets/gauravtopre/bank-customer-churn-dataset
